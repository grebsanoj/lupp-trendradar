# Trendradar från Lupp Studio

Månatlig genomgång för yrkesfotografer i Sverige: vad har hänt som påverkar intäkter, rättigheter, avtal och arbetsflöde, och vad bör man göra åt det.

Publiceras på lupp.se/trendradar.

## Så fungerar repot

- `brief.md` är den redaktionella briefen: urval, källor, statusetiketter och stil.
- `upplagor/ÅÅÅÅ-MM.md` är en fil per upplaga, namngiven efter månaden den täcker. Ny upplaga första tisdagen varje månad. Senaste filen i `main` är den som visas på lupp.se.
- Varje ny upplaga kommer som en pull request. Merge betyder godkänd och publicerad.

## Frontmatter i en upplaga

```
---
titel: Trendradar november 2026
period_start: 2026-11-11
period_slut: 2026-11-30
publicerad: 2026-12-01
---
```
